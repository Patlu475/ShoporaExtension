ShopBot Content Script Test Page

Instructions

This page is designed to test if your content scripts are loading properly. If the content scripts are working, you should see:

  1. A blue test box in the top-left corner saying "ShopBot Test Content Script Loaded!"
  2. A red debug alert in the top-left corner saying "ShopBot Content Script Loaded Successfully!"
  3. A grey "Extract" button in the bottom-right corner

Also check the browser console for log messages starting with [SHOPBOT].
